# nosDshell Documentation

nosDshell 用 deepin 15（DDE 15）的毛玻璃视觉与交互语言，提供 Noctalia v4（Quickshell/QML）的全套 Wayland 桌面能力。

nosDshell brings the classic deepin 15 (DDE 15) frosted-glass interface to Wayland, backed by the full Noctalia v4 (Quickshell/QML) engine.

## 内容 / Contents

- [Noctalia v4 Wiki 存档镜像](legacy/index.md)：上游 Noctalia v4 的完整文档，涵盖安装、配置、配色模板、插件开发和 IPC 接口。nosDshell 完整保留了 v4 的业务功能，文中配置与接口说明均可直接参考；界面形态与交互细节以本仓库的 [`DESIGN.md`](https://github.com/ShineBreaker/nosDshell/blob/main/DESIGN.md) 为准。

  _Archived mirror of the upstream Noctalia v4 documentation covering installation, configuration, color templates, plugin development, and the IPC reference. nosDshell keeps the v4 backend, so configuration and IPC docs apply directly. For visual design and surface behavior, [`DESIGN.md`](https://github.com/ShineBreaker/nosDshell/blob/main/DESIGN.md) in this repository is authoritative._

- [发版流程 / Release process](RELEASE.md)：版本号位置、自动化发版脚本、Tag 规范与重新开启开发周期。
