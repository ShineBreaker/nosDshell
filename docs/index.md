# nosDshell Docs

nosDshell 是一个 Wayland 桌面 shell，基于 Noctalia v4（Quickshell/QML），界面按 deepin 15（DDE 15）的视觉语言重做。

nosDshell is a Wayland desktop shell built on Noctalia v4 (Quickshell/QML), with every surface redrawn in the DDE 15 (deepin 15) visual language.

## 内容 / Contents

- [Noctalia v4 Wiki 存档镜像](legacy/index.md)：上游 Noctalia v4 的完整文档，包括安装、配置、主题、插件开发和 IPC 参考。nosDshell 继承了 v4 的功能，所以多数页面仍然适用；界面表现以本仓库的 [`DESIGN.md`](https://github.com/ShineBreaker/nosDshell/blob/main/DESIGN.md) 为准。

  _An archived mirror of the upstream Noctalia v4 documentation: install, configuration, theming, plugin development, and the IPC reference. nosDshell keeps the v4 feature set, so most pages still apply. For anything about how the shell looks or behaves on screen, `DESIGN.md` in this repo takes precedence._

- [发版流程 / Release process](RELEASE.md)：版号位置、打 tag 与 reopen。
