# nosDshell Docs

**nosDshell** 是一个以 deepin 15（DDE 15）视觉语言呈现的 Wayland 桌面 shell，基于 Noctalia v4（Quickshell/QML）。

nosDshell is a Wayland desktop shell that renders in the DDE 15 (deepin 15) visual language, built on Noctalia v4 (Quickshell/QML).
